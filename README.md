# Cyllee STEM Journey (standalone, Phase 1)

## Run locally
Service workers and ES modules need http, so do not double-click index.html.
    cd cyllee-stem-journey
    python -m http.server 8080        (or: python3 -m http.server 8080)
Open http://localhost:8080 in Chrome, Edge, Firefox or Safari.

## Install on a device
Host the folder on any static host (GitHub Pages, Netlify, Cloudflare Pages) over https.
- iPhone/iPad: Safari > Share > Add to Home Screen
- Android: Chrome > menu > Install app
- Windows/Mac: Chrome or Edge > install icon in address bar (Safari Mac: File > Add to Dock)

## Data
Stored in this browser's localStorage under keys starting `csj:`. Use Settings > Backup & Restore regularly.
